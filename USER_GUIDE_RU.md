# 🛡️ Руководство пользователя: Partizan VPN (Stealth WebRTC VPN)

Добро пожаловать в руководство по установке, сборке и использованию **Partizan VPN** — стелс-VPN нового поколения, маскирующего весь ваш трафик под обычный WebRTC-видеозвонок в инфраструктуре VK/OK. 

Данное руководство написано максимально простым языком и проведет вас от «чистой» Windows 11 до полностью рабочего безопасного соединения.

---

## 🚀 Быстрый старт для обычного пользователя (End-User)

Если у вас уже есть готовый собранный файл `Partizan VPN.exe`, вам не нужно устанавливать инструменты разработчика. Переходите сразу к этому разделу.

### Шаг 1. Запуск приложения
> ⚠️ **ОБЯЗАТЕЛЬНО**: Приложение Partizan VPN управляет сетевыми адаптерами и таблицей маршрутизации Windows. Поэтому его **ОБЯЗАТЕЛЬНО** нужно запускать от имени Администратора.
1. Кликните правой кнопкой мыши по файлу `Partizan VPN.exe`.
2. Выберите **«Запуск от имени администратора»** (Run as Administrator).

### Шаг 2. Получение ссылки для подключения
1. Перейдите в ваш Telegram-бот, привязанный к серверу VPN.
2. Отправьте боту команду `/new` (или воспользуйтесь кнопкой получения ключа).
3. Бот пришлет вам специальную ссылку вида:
   `myvpn://v1:xxxxxxx...`

### Шаг 3. Подключение
1. Скопируйте ссылку, полученную от бота.
2. Вставьте её в текстовое поле в окне Partizan VPN.
3. Нажмите кнопку **«Connect»** (Подключиться).

### Шаг 4. Интерактивная Капча (Важно!)
Так как подключение идет через официальные звонки VK, социальная сеть может потребовать проверку на робота (Капчу):
1. Если VK потребует капчу, приложение автоматически откроет окно браузера.
2. В открывшемся окне просто пройдите капчу (кликните «Я не робот» или решите картинку).
3. **Ничего больше делать не нужно!** Как только вы решите капчу в браузере, приложение само подхватит сессию, закроет окно и установит соединение.

### Шаг 5. Проверка соединения
После успешного подключения:
* В логах приложения появится надпись: `VPN Connected Successfully!`.
* Откройте сайт [2ip.ru](https://2ip.ru) в любом браузере — вы увидите IP-адрес вашего личного VPS-сервера.

## 🛠️ Инструкция по сборке из исходников (для разработчиков / владельцев VPS)

Если вы скачали репозиторий `vk-vpn` и хотите самостоятельно собрать клиент под Windows 11 с нуля, следуйте этой инструкции.

### Шаг 1. Подготовка окружения на чистой Windows 11

Для сборки проекта вам понадобятся три инструмента: **Go**, **Node.js** и **Wails**.

#### 1. Установка Go (Golang)
1. Перейдите на официальный сайт [go.dev/dl](https://go.dev/dl/).
2. Скачайте установщик для Windows (файл вида `goX.XX.X.windows-amd64.msi`).
3. Запустите установщик, нажимайте везде *Next* и завершите установку.

#### 2. Установка Node.js
1. Перейдите на сайт [nodejs.org](https://nodejs.org/).
2. Скачайте **LTS** версию установщика для Windows.
3. Установите его, соглашаясь со всеми настройками по умолчанию.

#### 3. Установка Wails CLI
Wails — это фреймворк, на котором написан графический интерфейс нашего приложения.
1. Откройте терминал **PowerShell** (нажмите `Win + X` -> выберите *Терминал* или *PowerShell*).
2. Выполните команду для установки Wails:
   ```powershell
   go install github.com/wailsapp/wails/v2/cmd/wails@latest
   ```
3. Убедитесь, что путь установки Go-бинарников добавлен в переменные окружения. Перезапустите PowerShell и введите:
   ```powershell
   wails doctor
   ```
   *Все пункты, кроме опциональных IDE, должны быть отмечены зелеными галочками.*

---

### Шаг 2. Сборка клиента

1. В PowerShell перейдите в папку с клиентом внутри скачанного репозитория:
   ```powershell
   cd c:\VPN\vk-vpn\vk-client
   ```
2. Запустите сборку приложения в режиме продакшена:
   ```powershell
   wails build
   ```
3. После завершения сборки готовый исполняемый файл будет находиться по пути:
   `c:\VPN\vk-vpn\vk-client\build\bin\Partizan VPN.exe`

---

### Шаг 3. Запуск в режиме разработки (для отладки)

Если вы хотите вносить изменения в код интерфейса (JS/HTML/CSS) или Go-логику и сразу видеть результат:
1. В папке `vk-client` выполните:
   ```powershell
   wails dev
   ```
2. Wails запустит приложение с поддержкой горячей перезагрузки (Hot Reload). Любые изменения в коде фронтенда или бэкенда будут мгновенно отображаться в запущенном окне.

## 🛟 Решение возможных проблем (Troubleshooting)

### ❌ Ошибка: «ICE: disconnected» или соединение обрывается через несколько секунд
* **Причина**: В сетевом стеке Windows накопились «мусорные» виртуальные адаптеры или зависшие маршруты от прошлых аварийных запусков.
* **Решение**: Просто перезагрузите ваш компьютер. Сетевой стек Windows полностью очистится, и приложение снова заработает стабильно.

### ❌ Ошибка: «failed to assign IP» или «could not find TUN interface»
* **Причина**: Приложение запущено без прав администратора.
* **Решение**: Закройте Partizan VPN и запустите его строго через правый клик -> **«Запуск от имени администратора»**.

### ❌ Медленно загружаются сайты при включенном VPN
* **Причина**: Наш VPN использует инновационную технологию маскировки под WebRTC медиа-потоки, которая оптимизирована под TCP-соединения. Запросы DNS (UDP) теперь автоматически идут в обход туннеля для максимальной скорости работы.
* **Решение**: Убедитесь, что в системе прописаны надежные DNS (например, `1.1.1.1` или `8.8.8.8`). Наш клиент автоматически настраивает обходные маршруты для этих DNS-серверов, гарантируя мгновенный резолв сайтов.
