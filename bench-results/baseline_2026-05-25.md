# Baseline 2026-05-25

Замер baseline'а на актуальном main для дальнейших сравнений throughput.

## Окружение

- **Build:** `vk-client.exe` свежий через `wails build`, ветка `bench/t1-kcp-sweep` (от main `57d0173`).
- **Server commit:** main 57d0173 (тот же, что и client).
- **Server ENV:** `VK_VPN_TUNNEL_MODE=kcp` (из systemd unit).
- **Client ENV (default):**
  - `VK_VPN_KCP_FEC = 10:3`
  - `VK_VPN_KCP_WINDOW = 2048`
  - `VK_VPN_KCP_MTU = 1200`
  - `VK_VPN_KCP_NODELAY = 1,10,2,1`
- **ICE policy:** `relay` (TURN-only).
- **Сетевые условия (клиент):** домашний Wi-Fi, время прогона 22:00 MSK (вечер).

## curl 92 MB (один прогон, 15-мин окно сглаживает шум)

```
bytes=96330730 time=589.762604s avg_kBps=163338
```

| Метрика | Значение |
|---|---|
| Bytes downloaded | 96 330 730 (100% от 91.86 MB) |
| Время | 589.76 с (9:50) |
| Avg goodput (curl) | **163.3 KB/s = 1.31 Mbps** |
| Last reported Current speed | 290.6 KB/s = **2.33 Mbps** (burst) |
| Использование канала (Диспетчер задач) | ~2.4 Mbps |

Соотношение «канал/goodput» = 2.4 / 1.31 ≈ **1.83×** — overhead DTLS+SRTP+RTP+ChaCha20+VP8+FEC parity. Норма для архитектуры Hybrid-B.

## Сравнение с предыдущими замерами

| Дата | curl avg sustained | Комментарий |
|---|---|---|
| 2026-05-24 (TRANSPORT_AUDIT.md) | ~1.2 Mbps | Hybrid-B первый прогон |
| 2026-05-25 утром (до wails-rebuild) | 0.88 Mbps | Старый бинарь, бракованная сборка через go build вместо wails build |
| **2026-05-25 вечером (этот baseline)** | **1.31 Mbps** | Свежая wails-сборка, default config |

Sustained пляшет день ото дня в диапазоне ~0.9–1.3 Mbps на одной и той же конфигурации. Это нормально — канал VK TURN не детерминирован.
